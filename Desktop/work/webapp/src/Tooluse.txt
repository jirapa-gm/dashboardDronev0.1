--------------------------------------------------------------------------------
1. ส่วนประกอบหลัก
--------------------------------------------------------------------------------

โฟลเดอร์: src/ 
 main.jsx        
 App.jsx         
 - เป็นศูนย์กลางของ State หน้าจอสลับแท็บเมนู และแจกจ่ายข้อมูลจาก useEvents
index.css       
 - ไฟล์รวมสไตล์ Vanilla CSS ทั้งหมดของโปรเจกต์ 

โฟลเดอร์: src/components/ 
 Navbar.jsx            
 - แถบเมนูด้านบน แสดงโลโก้ สถานะเครื่อง และปุ่มสลับ Live/Mock Mode
 Sidebar.jsx           
 - แถบตัวกรองการสืบค้นข้อมูลด้านซ้าย (Scope Tree และฟิลเตอร์ค้นหา)
 Summaries.jsx
 - รวมคอมโพเนนต์สรุปยอดสถิติรายระดับสำหรับการวิเคราะห์ (GroupSummary, SubgroupSummary, DetectorSummary)
 AnalyticsDashboard.jsx 
 - แท็บหลักการวิเคราะห์ (Analytics) แสดง KPIs สรุปผลรายชั่วโมงและรุ่นโดรนที่พบบ่อยที่สุด
TacticalMapView.jsx    
 - แท็บหลักแผนที่ (Tactical Map) ใช้ Leaflet Map พล็อตพิกัดโดรน พร้อมรัศมีภัยคุกคาม
 EventLog.jsx          
 - แท็บหลักบันทึกประวัติ (Event Log) แสดงตารางประวัติข้อมูลโดรนรายลำ(DroneIntelTable) และส่งออกรายงานเป็นไฟล์ CSV
 DroneHistoryPanel.jsx  
 - ป๊อปอัปแสดงประวัติแบบเจาะลึก 7 วันย้อนหลังของโดรนแต่ละเครื่อง
Charts.jsx             
 - ชาร์ต SVG ทั้งหมด เช่น ชาร์ตวงกลมทิศทาง, ชาร์ตวงกลมโมเดล,เกจความสูง, กราฟสปาร์กไลน์สัญญาณ RSSI และแท่งวันตรวจจับ

โฟลเดอร์: src/hooks/ 
useEvents.js    
 - ดึงข้อมูลด้วย TanStack Query ยิง 2 Queries เพื่อ Cache ข้อมูลแยกตามพิกัดแผนที่เรียลไทม์ (ทุก 3 วิ) และสถิติแดชบอร์ด (ทุก 60 วิ)
 useIsMobile.js  
 - ตรวจจับความกว้างของหน้าจอเบราว์เซอร์ เพื่อซ่อน/แสดง Sidebar บนมือถือ
 useSwipe.js     
 - ดักจับการปัดหน้าจอ (Swipe) ของมือถือเพื่อเลื่อนเปิดแถบ Sidebar
 useRipple.js    
 - จัดการแสดงผลระลอกคลื่น (Ripple Effect) เวลาเมาส์คลิกปุ่มต่างๆ

โฟลเดอร์: src/shared/
 constants.js    
 - ค่าคงที่ เช่น สีกลุ่มโดรน (GA/GB) ระดับความอันตราย และทิศทาง
 helpers.js      
 - ฟังก์ชันจัดการฟอร์แมตแปลงวันที่ ทิศทางองศา และสีแสดงระยะห่างโดรน
 icons.jsx       
 - ไอคอน SVG ทั้งหมดในแอปพลิเคชัน
 ui.jsx          
 - UI ส่วนกลางแบบนำกลับมาใช้ใหม่ได้ เช่น Card, Spinner, Toolbar, HBar

โฟลเดอร์: src/utils/ 
 chartUtils.js   
  - ฟังก์ชันคำนวณและจัดสรรข้อมูลดิบให้สอดรับกับความต้องการในการวาดกราฟแต่ละชนิด
 mapUtils.js
  - ฟังก์ชันคำนวณระยะทางแบริ่งทางภูมิศาสตร์ และตัวจัดฟอร์แมตข้อมูลแผนที่ Leaflet
 pdfTemplate.js
  - ฟังก์ชันจัดทำโครงสร้างเทมเพลต HTML/CSS สำหรับการสั่งพิมพ์และบันทึกรายงานเป็น PDF

โฟลเดอร์: src/data/ 
 Mockdata.js     
 - ข้อมูลจำลอง 
 mockData.json   
 - ข้อมูลจำลอง

--------------------------------------------------------------------------------
2. ส่วนประกอบหลักฝั่ง BACKEND 
--------------------------------------------------------------------------------
ทำหน้าที่รับ Request คัดกรอง คัดแยก และคำนวณข้อมูลสถิติสดส่งกลับให้ Frontend

โฟลเดอร์: Backend/
 main.py         
 - ทำหน้าที่เปิดจุดรับส่งข้อมูล API ยิงผ่านพอร์ต 8000 (http://localhost:8000/api/events)
